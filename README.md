# SchoolDesk - Frontend

Interfaz web de SchoolDesk en Angular 22 con Angular Material.

Backend: https://github.com/josramirez29/SchoolDesk_Backend

En construcción. La documentación completa se agrega al final.

## Cómo correrlo

Requisitos: Node.js 24 y el backend levantado (docker compose up -d).

```bash
npm install
npm start
```

La aplicación queda en http://localhost:4200 y habla con el gateway en
http://localhost:8000.
